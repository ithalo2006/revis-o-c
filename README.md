#Qual a saída do código? 

Se por exemplo o usuário digitar: 

5 11:

b = 11 

A condição: 
a > b || !  (a > 0) 
fica: 
5 > 11 || ! (5 > 0) 
false || false 
false 

Então executa o else: 
c = (float)(a / b) 

Mas a e b são inteiros, então: 
5 / 11 = 0 
c = 0 

Saída: 
0.00

while :

do while :
Primeiro executa
